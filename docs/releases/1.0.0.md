# LectureCaption 1.0.0

发布日期：2026-08-13

## 新增与改进

- 麦克风实时采集、本地输入活动检测、自动待机与手动暂停。
- 阿里云百炼实时 ASR，包含临时/最终字幕稳定和术语热词。
- DeepSeek `deepseek-v4-flash` 的有序中文翻译，包含课程、主题、术语表和近期上下文。
- 本地双语课堂记录、历史列表和详情查看。
- 跨桌面与全屏显示的非激活悬浮字幕窗，支持双语、原文、译文模式，以及直接可见的字号和背景透明度按钮。
- 主窗口在 macOS Spaces 切换后的焦点恢复修复。

## 验证

- SwiftPM 单元测试通过。
- Apple Silicon macOS Debug 与 Release 构建通过。
- 麦克风、实时转写、翻译、记录、主窗口 Spaces 行为和悬浮字幕的手工验收均已完成。

## 已知限制

- 仅支持麦克风输入；系统音频采集尚未恢复。
- MiMo 分块 ASR 在 MVP 后评估，未包含在本版本。
- 本地课堂记录可在应用内查看；Markdown 与 JSON 导出尚未实现。
- 2 小时稳定性尚未完成完整手工验收；当前仅完成 60 分钟连续运行测试。
- 睡眠/唤醒恢复尚未完成完整手工验收。
- Release 包采用 ad-hoc 签名；首次运行如被 macOS 拦截，请在“隐私与安全性”中确认打开。

## 发布例外

这是个人日常使用的首个稳定版本。项目原先为 `1.0.0` 设定的完整门槛包含 2 小时稳定性和睡眠/唤醒恢复验证；当前已完成 60 分钟连续运行测试。本次按发布者决定在 2 小时稳定性和睡眠/唤醒完整手工验收前发布，并将这些风险保留为已知限制，后续补充验证或以补丁版本修复。
