# LectureCaption 1.0.1

发布日期：2026-08-17

## 修复与改进

- Debug 与 Release 使用独立的本机配置、API Key 和课堂记录目录，避免测试环境影响正式版本。
- 本地课堂记录格式无效时保留原文件并显示完整路径，便于定位问题。
- 新增原生 macOS 应用图标。
- 正式产物统一为 `LectureCaption.app`、`LectureCaption.zip` 和 `LectureCaption.dmg`，版本号以应用元数据与 Git 标签为准。
