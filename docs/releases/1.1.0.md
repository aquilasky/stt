# LectureCaption 1.1.0

发布日期：2026-08-20

## 新功能

- 使用阿里云 ASR 句级时间戳建立连续课堂时间轴，并提供实时字幕、悬浮字幕与历史详情共用的显示开关。
- 历史记录详情支持导出 UTF-8 TXT 或稳定的 JSON 公开格式，并可选择是否包含时间戳。
- 主窗口支持 macOS 原生全屏。
- 新增防止系统自动息屏开关。
- 支持从一条或多条历史记录创建新的续录会话；源记录保留，并在新记录首次成功保存后标记合并目标。

## 已知限制

- 仅支持默认麦克风输入；不采集浏览器、会议软件或播放器的系统音频。
- 未针对 Intel Mac 优化或发布，且未经过 Apple 公证。
- MiMo ASR、离线识别、云同步、Markdown 导出和历史记录编辑未包含在本版本。
- 持续、低音量且稳定的输入可能误触发自动待机，详见 [Issue #53](https://github.com/aquilasky/stt/issues/53)。
