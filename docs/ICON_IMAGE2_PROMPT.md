# LectureCaption 图标生成提示词

将以下内容直接交给 image2：

```text
Create an original macOS application icon for "LectureCaption", a real-time bilingual lecture caption app. The visual language should feel native to modern Apple first-party macOS apps: precise, calm, premium, simple, tactile, and immediately legible at 16 px through 512 px.

Icon concept: a centered caption card containing two short horizontal text lines, with a restrained live-audio waveform integrated beneath the lower line. The form should communicate listening, spoken language, and live subtitles without using letters, Chinese characters, English text, microphone silhouettes, flags, or a generic chat bubble. Use layered translucent glass-like panels with subtle depth, crisp geometry, soft shadows, and controlled highlights. Primary palette: luminous aqua/cyan with a small warm coral accent on a neutral graphite-blue background. Keep contrast strong and the composition balanced in a macOS rounded-square app-icon canvas.

Output a single 1024 x 1024 square PNG, no transparency, no border, no external frame, no mockup, no device, no text, no watermark. It must be an original design: do not include the Apple logo and do not copy any identifiable existing Apple app icon.
```

生成后优先选择在深浅两种 macOS 壁纸上均有清晰轮廓、缩小后仍能辨认“两行字幕 + 波形”结构的版本。
