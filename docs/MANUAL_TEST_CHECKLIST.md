# LectureCaption 手工测试清单

> 适用范围：无法由自动化测试可靠覆盖的 macOS 权限、真实音频、窗口交互、长时间运行与外部网络场景。
> 执行人：项目用户或其明确委托的测试者。
> 主代理职责：提供可复现的步骤、审阅结果、修复失败项并重新安排回归测试。

## 1. 执行规则

- 每个用例只能记录为“通过”、“失败”或“阻塞”；未执行不等同于通过。
- “失败”必须记录实际输出、发生时间和复现步骤；不要粘贴 API Key、完整授权令牌或课堂敏感内容。
- 系统权限修改、管理员认证、真实课堂音频播放和 60 分钟运行由执行人操作，主代理不代替执行。
- 一个 Feature 的所有标记为“必测”的用例通过后，才能完成对应 Feature、将 Draft PR 转为 Ready 或开始下一个 Feature。

## 2. 记录模板

在 PR 的 `Manual validation` 区域按下面格式记录每个用例：

```text
MAN-XXX: 通过 | 失败 | 阻塞
设备与系统：<Mac 型号 / macOS 版本>
输入：<实际输入或音频来源>
实际输出：<观察到的界面与行为>
备注：<失败信息、截图路径或复现条件；不得包含密钥>
```

## 3. 启动测试 App

1. 在 Finder 或 Xcode 中打开 `LectureCaption.xcodeproj`。
2. 在 Scheme 菜单选择 `LectureCaption`，运行目标选择“我的 Mac”。
3. 按 Command-R 构建并启动 Debug App。
4. 在开始 MAN-001 前，记录 Mac 型号、macOS 版本、输入设备和当前是否已授权麦克风。

命令行构建仅用于确认项目可编译，不能代替实际 App 测试：

```bash
xcodebuild -project LectureCaption.xcodeproj \
  -scheme LectureCaption \
  -destination 'platform=macOS,arch=arm64' \
  build
```

## 4. Stage 1：音频采集与本地待机

### MAN-000 启动并显示主窗口（必测）

前置条件：`LectureCaption` 未运行；已在 Xcode 中选择 `LectureCaption` Scheme 和“我的 Mac”运行目标。

操作：按 Command-R，等待构建和启动完成。

输入：无。

预期输出：

- `LectureCaption` 进程保持运行，并显示一个标题为“LectureCaption”的主窗口。
- 主窗口包含会话设置和“等待字幕”预览区域，窗口位于任一已连接显示器的可见区域。
- 不应只出现 Dock 图标、空白窗口或立即退出。

### MAN-001 麦克风权限状态与请求（必测）

前置条件：打开刚构建的 `LectureCaption.app`；系统设置中未授权或已撤销该 App 的麦克风权限。

操作：

1. 点击工具栏“开始”。
2. 在 macOS 提示框选择“允许”，或选择“不允许”。
3. 若选择“不允许”，在系统设置的“隐私与安全性 > 麦克风”中手动恢复授权，再回到应用点击“开始”。

输入：选择“允许”或“不允许”之一。

预期输出：

- 首次点击“开始”时由 macOS 显示麦克风授权提示。
- 允许后会话进入“本地监听”，顶部 dBFS 数值开始刷新。
- 拒绝后应用显示“未获得麦克风权限。”错误提示，不崩溃，不开始采集。

### MAN-002 麦克风实时采集与停止（必测）

前置条件：MAN-001 已授权。

操作：

1. 点击“开始”，正常说话 5 秒，然后保持安静 3 秒。
2. 观察顶部 dBFS 数值和“本地监听/检测到输入”状态。
3. 点击“结束”。

输入：正常人声与静音。

预期输出：

- 说话时 dBFS 相比静音明显升高，状态在约 200 ms 后变为“检测到输入”。
- 静音后约 600 ms，状态恢复“本地监听”。
- 点击“结束”后会话状态为已结束，dBFS 不再持续刷新；再次点击“开始”可重新采集且不崩溃。

### MAN-003 手动暂停不被声音解除（必测）

前置条件：麦克风正在采集且显示“检测到输入”。

操作：点击“暂停”，然后持续说话 5 秒，再点击“继续”。

输入：持续人声。

预期输出：

- 暂停期间会话保持“手动暂停”，不会因声音自动变为识别中。
- 点击“继续”后返回“本地监听”；再次检测到声音时可恢复输入活动。

### MAN-004 自动待机与恢复（必测）

前置条件：自动待机选择“15 秒”，麦克风正在采集。

操作：

1. 先说话 2 秒以激活本地活动检测。
2. 保持静音至少 16 秒。
3. 再说话 2 秒。

输入：人声、至少 16 秒静音、再次人声。

预期输出：

- 静音达到阈值后，状态变为“自动待机”。
- 再次说话时约 200 ms 后恢复本地活动；不需要重新点击“开始”。
- 后续 Stage 2 接入云端后，需额外验证预滚 PCM 不漏首音节。

### MAN-005 连续运行 60 分钟（必测）

前置条件：已验证的麦克风采集正在运行；Activity Monitor 可用。

操作：

1. 点击“开始”，持续播放课程音频或保持正常课堂环境 60 分钟。
2. 在第 0、10、20、30、40、50、60 分钟记录 Activity Monitor 中 `LectureCaption` 的内存和 CPU。
3. 期间至少执行一次静音到自动待机、一次恢复声音、一次结束并重新开始。

输入：不少于 60 分钟的连续真实音频，包含至少一次静音区间。

预期输出：

- 应用不崩溃、不假死，开始/结束/重新开始均有效。
- 内存不会持续单调增长；CPU 没有持续异常占用。
- 本地活动、自动待机和恢复行为与 MAN-004 一致。

记录附加字段：各时间点内存、CPU、麦克风设备与任何异常。

### MAN-006 Dock 与任务视图激活（必测）

前置条件：`LectureCaption` 未运行；当前桌面至少有一个其他应用窗口。

操作：

1. 在当前桌面中按 Command-R 启动 `LectureCaption`。
2. 观察 Dock 是否出现 `LectureCaption` 图标，并确认主窗口位于当前桌面且获得焦点。
3. 切换到另一个应用，再点击 Dock 中的 `LectureCaption` 图标。
4. 打开任务视图，选择 `LectureCaption` 主窗口。
5. 结束应用，确认 Dock 图标随进程退出而消失。

输入：Command-R、Dock 图标点击和任务视图中的主窗口点击。

预期输出：

- 应用运行时 Dock 显示 `LectureCaption` 图标。
- 从 Dock 或任务视图选择窗口后，窗口在当前桌面前置并获得键盘焦点。
- 不需要将窗口拖动到其他桌面，也不会因激活而创建或切换到新的桌面。

## 5. 后续 Feature 手工测试

### MAN-100 阿里云实时原文与密钥存储（必测）

前置条件：阿里云百炼已开通实时语音识别；已取得有效的 Workspace ID 和 DashScope API Key；已确认 Workspace 所在地域（新加坡或北京）；麦克风权限已授予。

操作：

1. 在“阿里云识别”中填写 Workspace ID 和 API Key，选择与 Workspace 匹配的“地域”（新加坡或北京），选择“阿里云实时”，点击“开始”。
2. 正常说一段至少 10 秒的英文或中文，包含一个术语表中的词；中途停顿 2 秒后继续说话。
3. 点击“结束”，再次点击“开始”，但不重新填写 API Key，再说一段短句。

输入：有效 Workspace ID、有效 API Key、至少两段自然语音和一个术语表词。

预期输出：

- 首次有效输入后状态短暂显示“正在连接”，收到服务端响应后显示“正在识别”。
- 原文预览中先出现较浅的临时文本，断句后更新为稳定文本；已确认文本不再跳动或重复。
- 点击“开始”后 API Key 输入框立即清空并写入本机 `LocalCredentials.json`；第二次开始不重新输入 API Key 仍能连接，且 API Key 不出现在错误提示、日志或预览中。
- 结束后不再产生新字幕；已有字幕保留在预览中。

### MAN-101 阿里云实时错误与自动待机（必测）

前置条件：MAN-100 已通过；麦克风正在采集，自动待机选择“15 秒”。

操作：

1. 开始会话，说话 2 秒后保持静音至少 16 秒，再说话 2 秒。
2. 停止会话，将 Workspace ID 改为无效值，再开始并说话。

输入：有效识别会话中的静音恢复；无效 Workspace ID。

预期输出：

- 静音阈值后界面变为“自动待机”，不再继续发送云端音频；再次说话后自动重新连接并恢复字幕。
- 使用无效 Workspace ID、错误地域或无效 API Key 时，界面显示“阿里云 WebSocket 连接失败”，并提示检查 API Key、Workspace ID 和地域；不得显示 API Key。
- 无效配置时显示清晰的连接或鉴权错误，应用不崩溃；已有字幕不丢失，麦克风本地监听仍可结束。

实时翻译、悬浮字幕、导出和睡眠恢复在对应 Feature 开始前，必须先向本清单补充编号用例。每个新用例必须包含前置条件、明确操作、输入、预期输出和记录字段。
